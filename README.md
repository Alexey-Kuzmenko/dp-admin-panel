# Admin panel for a portfolio website

This application serves as the admin panel for my personal portfolio website. It allows you to manage the website's content, such as text, icons and images.

[Link to portfolio website repository](https://github.com/Alexey-Kuzmenko/developer-portfolio) <br>
[Link to developer portfolio API repository](https://github.com/Alexey-Kuzmenko/developer-portfolio-api)

Used technologies:

- React
- TypeScript
- Vite
- Axios
- SCSS
- Material UI
- React Hook Form
